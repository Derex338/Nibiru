## Сборка

1. Склонируйте этот репозиторий локально.
2. Скачайте [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).
3. Выберите вариант билда для работы.

### Конфигурации сборки

| Скрипт | Конфигурация | Когда использовать |
|---|---|---|
| `buildAllDebug` | Debug | Обычная разработка: отладка, брейкпоинты, лишние проверки. Медленнее и менее стабильно на больших картах. |
| `buildAllRelease` | Release | Как на живом сервере: оптимизации, без отладочного оверхеда. |
| `buildAllTools` | Tools | Маппинг и работа с инструментами редактора. |

Для **маппинга** собирайте **Tools** (`buildAllTools`): карта грузится быстрее, меньше крашей. Release тоже подойдёт по производительности, но Tools - предпочтительный вариант.

Windows: `Scripts/bat/buildAllDebug.bat`, `buildAllRelease.bat`, `buildAllTools.bat`  
Linux / macOS: те же имена в `Scripts/sh/` с расширением `.sh`

Запускать `RUN_THIS.py` не обязательно. Эти скрипты сами подтянут движок и подмодули.

### Запуск

Скрипты `runQuick*` **не собирают** проект - перед ними нужен хотя бы один `buildAll*`.

- `runQuickAll` - клиент и сервер вместе (обычный локальный запуск, по сути просто запускает два следующих файла)
- `runQuickClient` - только клиент (полезно когда нужно, например, два игрока на сервере одновременно)
- `runQuickServer` - только сервер

Windows: `Scripts/bat/runQuickAll.bat`  
Linux / macOS: `Scripts/sh/runQuickAll.sh`
 

[Более подробная инструкция по запуску проекта.](https://docs.spacestation14.com/en/general-development/setup.html)
