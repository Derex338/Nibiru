# Руководство по контрибьюции Space Station 14

Спасибо, что вносите вклад в Space Station 14.
При контрибьюции следуйте [соглашениям кодовой базы](https://docs.spacestation14.com/en/general-development/codebase-info/codebase-organization.html) и [руководству по PR](https://docs.spacestation14.com/en/general-development/codebase-info/pull-request-guidelines.html).

Соблюдение этих правил ускоряет ревью, поэтому обязательно прочитайте связанные документы целиком.

Последнее крупное обновление руководства: **6 декабря 2025**.

### Зачем этот файл?
Он нужен для того, чтобы GitHub уведомил вас при создании pull request, если руководство по PR изменилось и вы ещё не читали актуальную версию.
